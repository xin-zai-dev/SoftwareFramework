# SCARA 机械臂实验室

本工程新增四轴 SCARA 仿真，继续使用 Qt6/C++17/CMake，默认不需要机器人 SDK 或额外安装3D引擎。左侧“机械臂实验室”同时在设计模式和客户运行模式可见。

## 打开

Mac 双击根目录 **启动机械臂仿真.command**。Qt Creator 可使用如下运行参数：

```text
--project <本工程路径>/examples/scara-sorting.ivproj --workspace <本工程路径>/scara-lab --robot-console
```

内置新工程有 `robot-1`。旧工程不含机械臂时，可在实验室点击添加仿真机械臂，再保存工程；设备配置页也提供添加按钮。客户运行模式请使用发布时已经包含仿真机械臂的工程。

## 手动操作

1. 选中 `robot-1`，确认机械臂使能、设备在线且虚拟急停已解除。
2. 关节模式下填写 J1/J2/Z/J4 或拖动滑块，点击应用关节目标；点动按钮适合逐步观察姿态变化。
3. XYZ模式下填写目标 X/Y/Z/R，选择肘型，点击移动。也可点击画布底板设置目标XY，保留目标Z/R后再发令。超出可达范围会显示原因。
4. 调整速度比例1..100%。回待机位恢复默认关节位置；停止会停在当前位置，不会把未完成动作当作已经到位。
5. 在料位附近下降到Z=20，闭合夹爪抓取；抬升后移到料箱附近，下降并张开夹爪，观察工件跟随和料箱计数。

默认两臂长180/140 mm，J1/J2为±170°，Z为0..150 mm，J4为±180°。显示的TCP R是工具方向，包含两个平面关节和腕关节的合成角度。XYZ移动提供可达终点定位，运动采用关节空间同步插补。

料位坐标为(220,40,20)，OK箱为(80,200,20)，NG箱为(80,-200,20)，距离15 mm内视为对应抓放区域。夹爪在其他位置张开会留下散落工件。手里拿着工件时不能补料；先放下，再点击补一件。

## 一键抓取与分拣

先点击补一件，再选择分拣到OK或NG。仿真会依次执行：料位上方→下降→闭合夹爪→抬升→料箱上方→下降→释放→抬升。画布显示轨迹、夹爪状态和料箱累计计数。执行中可停止或急停，解除后需重新发令。

## 示教与回放

把机械臂移动到要记录的位置，设置夹爪开合并填写点名，点击记录示教点。列表保留每个点的关节姿态及夹爪状态，最多100点，可删除、移动到选中点或按顺序回放。播放时每到一点再应用该点夹爪状态，因此可示教一段抓放动作。

用保存/加载按钮将示教保存为 JSON 文件，默认目录位于本工程 workspace。文件不需要写代码，后续可加载重复演练。非法文件不会覆盖当前有效点位。全局虚拟状态重置保留当前示教点，新建或打开其他工程会清除本次点位；跨进程复用请保存示教文件。

工程附带 `examples/scara-teaching-demo.ivrobot.json`，可直接加载并回放一段“抓取→送入OK箱→回待机位”的7点程序。回放前确认料位有工件，必要时先补一件。

## 与视觉检测联动

`scara-sorting.ivproj` 在原有检测链之后增加机械臂分拣节点：

```text
人工/自动触发 → 运动定位 → 开灯 → 采图 → 测量 → 判定 → 保存记录 → I/O输出 → SCARA抓取分拣
```

在仿真控制台关闭自动到位触发、选择触发设备plc-1，点击单次检测，再点击触发一件；切回机械臂实验室观察动作。合格件进入OK箱，超差件进入NG箱。示例节点启用restock=true，明确模拟每个周期的自动供料；手动操作则通过补一件按钮补料。

流程执行期间机械臂手动发令和示教编辑会锁定，停止和急停仍可使用。记录已保存但分拣尚未完成时，软件仍处于运行状态；全链路结束后才结束单次检测。后续分拣失败不会撤销已经保存的检测记录。

可添加的流程节点为 `robot_move`（XYZ/R定位）、`robot_grip`（夹爪）及 `robot_sort`（根据已保存检测结果分拣）；多机械臂项目要显式指定deviceId。

这是软件运动学、动画和虚拟抓放模型，不包含真实机器人控制、伺服动力学、碰撞检测或现场安全联锁。相机仍检测合成工件图像，机械臂依据该检测结果执行虚拟分拣。
