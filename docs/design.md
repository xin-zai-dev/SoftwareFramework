# Industrial Vision Studio 设计与交付范围

用户已批准在当前目录使用 C++ 实现完整可运行 Qt 工程，沿用本次对话设计，不再停在需求评审阶段。

## 目标
Qt 6.5+ / C++17 / CMake，Windows x64 优先，核心兼容 macOS/Linux。Qt Widgets UI、应用编排、设备/存储接入三层。无商业 SDK 时可用模拟设备完整演示：配置、拖拽流程、检测、数据绑定、百万条历史查询、工程保存与独立运行包。

## 本次实现
- 顺序流程编辑器：拖入/重排节点，编辑节点参数，发布前校验。
- 设备接口、真实 Modbus TCP 客户端、模拟相机/运动/光源/PLC/I/O；厂商候选型号目录明确区分适配状态。Hikrobot MVS 可选 SDK 构建；未提供的专用 SDK 不能被伪装成已支持。
- 相机分辨率可选；合成图像通过真实阈值/几何算法计算检测值；可选 OpenCV 算法，HALCON 为可选构建/诊断入口，不内含授权。
- 工作线程执行流程和写数据库，主线程仅负责界面；停止取消后续节点，错误进入故障态。
- SQLite 和 SQL Server/QODBC 数据仓库；百万条记录、索引、游标分页、CSV 导出、独立压力测试库。
- 图像、结果表、趋势图、散点图、日志等可配置页面及字段绑定；图表自绘，无额外 Charts 模块依赖。
- 版本化 JSON 工程，模拟默认工程；客户运行模式；当前平台可发布独立运行目录，Qt 部署工具收集运行库，不声称从 macOS 直接生成 Windows 二进制。

## 约束
- 累计至少 1,000,000 条检测记录，图像另设策略；数据默认在当前工程目录/data。
- Qt Creator 打开根 CMakeLists.txt 可构建；SDK/OpenCV/HALCON 默认关闭，不自动下载依赖。
- 默认 1,000 ms/件，分辨率2448×2048；数据模型以一次工件检测为一条，测量单位 mm，像素标定参数可配置（模拟默认20 px/mm）。
- GUI 模拟停止不代表硬件急停；实际运动/触发/联锁需控制器与项目验证。
- 验收：实际编译、自动化测试、模拟端到端、百万条基准、部署目录无开发环境路径依赖验证。

## 验收重点
损坏工程不得覆盖正在使用的工程；非法顺序/尺寸/字段/设备配置须被拒绝；写入失败不能计为已保存；后台线程退出干净；CSV处理逗号/换行及表格公式前缀；发布不能递归复制自身或悄悄带入生产数据库和密码。
